# Report catalog and comparison foundation

The catalog contains stable versioned discovery metadata; it is not an access grant, database configuration store or arbitrary query engine. The existing /reports route hosts provider delivery and registration-cohort outcomes. Class, Site, Go Link and infrastructure reports retain their respective resource-specific workflows. Network impact is explicitly unavailable until canonical principal, host metric grants and disclosure governance are independently established.

The private query hook includes current workspace identity and the exact report/resource/date selection, never uses previous data placeholders, hides data during refetch/error and disables reads when session verification is missing. Server functions remain authoritative. Provider summary consumers share the identical query key and reader. The provider release chart follows the existing Site selection without recalculating unique people or sums.

The shared UTC date control uses completed days and exclusive end. Class and noncredit outcomes reuse it. Class comparison is between equal-duration independently fetched cohorts, only with matching contract versions. It is not an as-of reconstruction, and missing counts produce no delta. Existing private CSV export remains unchanged except that unavailable data is not exposed while refreshing.

Required release evidence: full npm install, typecheck, lint, unit and Storybook execution, Cloudflare build, authenticated provider and Class navigation, scope switch, denied endpoint, missing metrics and date-range browser tests. No database migrations or new access grants.

# CAN OS — School family brand integration (7 designs)

## Purpose

Website & Brand Studio is the single source of school visual identity. This
implementation connects the existing seven Site templates with an authorized
family-interest introduction, a 3-minute survey, and three email compositions
per design. This work reuses canonical school Site, Program, Communication,
Action, public admissions interest and audit/event services. It does not create
a parallel CRM or child/household enrollment record.

## Seven selected visual systems

- `heritage` — classical editorial / navy / gold
- `community` — welcoming community bulletin / green / rounded
- `modern` — contemporary high-contrast / digital school notes
- `bright-futures` — cheerful, open layouts / blue / warm accent
- `summit` — monumental high-contrast / deep blue / brass
- `classic` — scholarship / serif / bordered
- `campus` — school journal / contemporary and graphic

The brand is resolved from the **latest saved Site-local content revision** (or
the starter on an unsaved Site). The editable website and family collateral
share the same approved bounded palette and font tokens. Only the mark derived
from the actual school name is shown. The supplied ZIP's sample-school
photographs and logos are references and are **not silently published**.
The email HTML deliberately avoids remote image calls, remote CSS and imported
font files.

## Studio and Launch Hub

`/launch/website` → **Your school brand** exposes five private, authenticated,
read-only examples, and Recruit Families exposes the same links:

- `/brand-preview?siteId=<uuid>&view=landing`
- `/brand-preview?siteId=<uuid>&view=survey`
- `/brand-preview?siteId=<uuid>&view=email-survey`
- `/brand-preview?siteId=<uuid>&view=email-confirmation`
- `/brand-preview?siteId=<uuid>&view=email-update`

The viewer verifies the existing CAN OS session, exact Site grant and canonical
website editor relationship. The forms are disabled; no contact details are
submitted, no email is sent and no website is published.

## Live Program-linked preopening family invitation

An authorized **registrar** may use the existing preopening
`sendFamilyInvitationBatch` + domain-event outbox, which already enforces
scope, recipient deduplication, retries, secure origin, 30-day link lifetime
and synthetic-tenant delivery suppression.

When that existing flow sends an *interest* invitation:

1. It reads the saved Site brand and renders the matching email-safe survey
   invitation (with a plain-text fallback) through the existing Resend sender.
2. Its opaque per-recipient URL points to `/family/interest`, which renders the
   branded school-interest landing page. `?view=survey` renders the matching
   three-minute survey. The route validates the original recipient, Program,
   token expiry and same-origin POST; requests remain bounded and rate-limited.
3. An adult can affirmatively request follow-up. The response is saved through
   the existing `publicAdmissionsInterests` intake and canonical Action
   follow-up. The same contact may also add survey answers without creating
   a second lead.
4. The survey can record `contactPreference=none`, in which case no follow-up
   Action or confirmation email is created. A later no-contact choice withdraws
   consent and resolves an open follow-up; a later affirmative opt-in can restore
   that follow-up.
5. After opt-in, a branded confirmation template is submitted through the
   existing email transport with a stable idempotency key. A provider failure
   does not erase the stored response; provider acceptance is not mailbox
   delivery confirmation.

All pages maintain explicit school-development or information-only status.
No application, child identity, admission, tuition or operating authorization
is generated by the collateral.

## Deliberate limits and next required capabilities

- **Site-only concept outreach before Program creation** is a separate planned
  task; the existing live invitation outbox remains Program-scoped. Do not
  silently coerce an unconfigured Site into a fake Program.
- The **family update** email composition is ready for preview and use by a
  future audited, consented campaign dispatcher; no mass-email sending action
  has been invented. The existing mail outbox now sends the initial branded
  survey invite, and the opt-in response can send a branded confirmation.
- The historical ZIP includes decorative sample school images. Reuse of
  independent school media will require actual asset-rights, child-image
  consent and publication review. No external stock images are copied.
- This source change does not constitute a live Cloudflare or Netlify deploy.
  End-to-end acceptance must test both hosts, including URL origins, real
  sender settings, opt-out/retry, and active Program status changes.
